# Level7 — Approved Specification

> Only player-approved/frozen requirements belong here. Proposals remain in `DESIGN.md`.

## 1. Entry progression

- Level6 victory unlocks **句芒** through shared progression data.
- Level7 entry uses the existing Level4+ lineup flow.
- Owned eligible roster at Level7 entry:
  - 畢方
  - 夫諸
  - 應龍
  - 白澤
  - 句芒
- Player selects exactly **3**.
- Retry returns to empty **0/3**.
- Blessing filtering uses the selected lineup.
- No Level7-only hard-coded roster array.

## 2. 句芒 availability / identity

- Level7 is the first playable level where 句芒 can be selected.
- 句芒 role direction is **global ally-support / wood-god support**.
- It is not a short-range aura unit.
- It must remain mechanically distinct from 白澤's enemy-side Insight/debuff identity.
- Exact cost/damage/interval/range/support multiplier/projectile/Blessings are **not yet approved**.

## 3. Newly unlocked reminder

- On the player's first relevant Level7 lineup experience, 句芒 should be visibly discoverable as newly available.
- Any `NEW` / newly-unlocked emphasis is presentation-only.
- The implementation must be shared/data-driven so future beast unlocks can reuse it.
- It must not create a Level7-specific progression state or roster branch.

## 4. Shared inherited requirements

Level7 inherits all applicable `AGENTS.md` rules, including:

- Chat-first / minimal Work delta.
- Completed Level1–6 compatibility.
- shared Motion Lite;
- enemy path-facing / tower target-facing;
- global spacing/readability;
- data-driven roster/Blessing/progression;
- canonical geometry discipline;
- mobile 390px / 390×700 acceptance;
- Section 16 attack-visual classification;
- Section 17 active-level continuity/read order;
- default release closure through main + Pages unless explicitly overridden.
